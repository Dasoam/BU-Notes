## About BU Notes

BU Notes is designed to streamline academic preparation for Bennett University students by providing a centralized platform for accessing up-to-date, high-quality notes for various courses. The app is available on the [Google Play Store](https://play.google.com/store/apps/details?id=com.dhdash.bunotes&hl=en_IN), but is **exclusively accessible to Bennett University students**.

---

## Features

- **Curated Course Notes:** Access well-organized, subject-wise notes for all major courses.
- **Regular Updates:** Materials are updated to reflect the latest curriculum and exam requirements.
- **Exclusive Access:** Only Bennett University students with valid credentials can use the app.
- **User Privacy:** No user data is collected or shared; all data is encrypted in transit.
- **Simple Interface:** Clean, user-friendly design for quick navigation and note retrieval.

---

## Privacy & Data Policy

- **No Data Collection:** BU Notes does not collect or share any personal data.
- **Encryption:** All data transmitted is encrypted to protect user privacy.
- **User Control:** Users can request data deletion at any time.
- **No Third-Party Sharing:** Your information is never shared with third parties.

For more details, refer to the [Privacy Policy](https://play.google.com/store/apps/details?id=com.dhdash.bunotes&hl=en_IN).
